# EISUS Control 📱⚡

تطبيق الموبايل المصاحب لنظام **EISUS Smart Home & Hub** (Android Native Companion App).

يتيح تطبيق **EISUS Control** للمستخدم النهائي التحكم الكامل في شاشة ومنظومة EISUS الذكية عن بعد من أي مكان في العالم عبر النفق السحابي المشفر بدون الحاجة لمعرفة الروابط أو التفاصيل التقنية.

---

## ✨ المميزات الرئيسية
1. **تسجيل دخول آمن وسريع (Zero-Config Connection)**:
   - يحتاج المستخدم فقط لإدخال معرّف الشاشة الخاص به (`Hub ID` مثل `id-de6eff0f`).
   - تسجيل الدخول باسم المستخدم أو البريد الإلكتروني وكلمة المرور الخاصة بحسابه على الشاشة.
   - التحقق وتخزين الـ Token محلياً بأمان.

2. **عرض لوحة التحكم المتقدمة (Responsive Web Dashboard)**:
   - واجهة تحكم متجاوبة بالكامل تدعم التمرير، السحب للتحديث (Pull-to-Refresh)، والتفاعل اللحظي.
   - دعم التبديل السلس بين شاشة التحكم الرئيسية ونظام **Home Assistant** المضاف على الشبكة بضغطة زر واحدة.

3. **حماية الروابط العامة**:
   - يتم إخفاء الروابط والنطاقات المشفرة تماماً عن الواجهة لضمان تجربة مستخدم مبسطة وحماية الروابط من التسريب.

---

## 🛠️ متطلبات البناء
- Android SDK 30+ (Min SDK 24)
- JDK 17
- Jetpack Compose & Material 3
- OkHttp 4.12
- WebKit WebView مع دعم DOM Storage و JavaScript
